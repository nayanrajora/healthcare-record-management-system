# Healthcare Record Management System Using Blockchain Technology

> **College Major Project (B.Tech Computer Science & Engineering)**  
> Built with Python 3.11, Flask, SQLite, and an educational SHA-256 cryptographic hash chain.

All project code, tests, templates, and documentation are located in the [`HealthcareBlockchain/`](HealthcareBlockchain/) directory.

### Quick Start:
1. Open PowerShell or Command Prompt:
   ```powershell
   cd "E:\Healthcare Record Management System\HealthcareBlockchain"
   .\.venv\Scripts\Activate.ps1
   python app.py
   ```
2. Navigate to: `http://127.0.0.1:5000/`
3. Log in with:
   - **Admin:** `admin` / `Admin@123`
   - **Doctor:** `dr_sharma` / `Doctor@123`
   - **Patient:** `john_doe` / `Patient@123`

### Run Automated Tests (30/30 Tests Passing):
```powershell
python -m unittest discover tests
```
